# 紫微斗数排盘系统 — 全栈落地项目计划书

> 最后更新：2026-07-30
> 项目仓库：`ziwei-dou-shu/`

---

## 一、项目总目标

1. 产出**三套可运行载体**：开源 Github 算法库、PC 精美网页排盘系统、微信小程序排盘工具，三者共用同一套底层紫微算法，数据互通、计算结果完全一致。
2. 完成**紫微全算法逐行校验校正**（基础排盘、四化、宫星、流月流日、大限、流年、十二长生、庙旺落陷、格局判定等核心逻辑），杜绝市面开源代码普遍存在的历法偏差、节气换算错误、四化取法版本混乱问题。
3. UI 要求：厚重传统彩绘中式风格、分层排版清晰、交互顺滑、信息分区合理，兼顾新手易懂 + 专业从业者精细化查看需求。
4. 整体分为：算法层 → 网页端 → 小程序端 → Github 开源封装 → 测试校正 → 上线部署，分阶段执行，可分步交付核验。

## 二、整体架构分层（解耦设计，方便维护校正）

### 2.1 底层核心层（最关键：算法校验区）【优先级最高】

> 网页、小程序全部调用纯 TS 算法，一处修改全端同步更新。

#### 模块清单 & 校正校验要点

| 算法模块 | 包含内容 | 校正核验标准 |
|---------|---------|-------------|
| 历法换算核心 | 公农历互转、节气精准计算、真太阳时换算、时区修正、北京时间→地方平太阳时纠偏 | 对标《紫微斗数全书》历法规则 + 紫微通行排盘软件（元亨利贞、文墨天机）实测 100 组生日盘面比对，误差必须为 0 |
| 命盘基础排布 | 命宫/身宫、十二宫排布、五行局定局、紫微星安星法、南北斗全部主星辅煞排布（108 颗星曜完整排布） | 逐颗核对安星口诀，区分多流派切换 |
| 四化系统 | 天干四化、大限四化、流年四化、流月流日四化 | 区分固定四化、随局四化两种写法，逐个天干校验盘面结果 |
| 星曜属性库 | 庙旺落陷表、星曜五行、星曜吉凶、星曜亮度等级、双星同宫合断规则 | 整理权威典籍原始对照表，修正网上流传错误的庙旺表格数据 |
| 运势推演 | 大限排布、小限、流年、流月、流日、流时盘、斗君、岁建、流年煞星排布 | 匹配流年起运岁数计算（虚岁换算精准计算），批量测试不同出生年份大运盘面 |
| 格局自动判定 | 六十余种常见紫微格局（杀破狼、机月同梁、紫府同宫、日月并明等） | 编写格局触发逻辑，对照专业软件格局标识一一校准判定条件 |
| 杂项计算 | 十二长生、空亡、天罗地网、博士十二神、将前十二神、长生十二神 | 逐条匹配古籍排布顺序 |

### 2.2 流派切换机制（用户确认）

**支持四种主流流派作为排盘模式选项：**

| 流派 | 差异点 | 实现方式 |
|------|-------|---------|
| **三合派（默认）** | 中州派安星法，三合飞星，十二宫星曜分布标准 | 基准算法 |
| **飞星派** | 四化触发方式不同（重四化飞转），宫位之间飞化关系 | 四化模块增加飞星分支 |
| **四化派（钦天）** | 以四化为主线，星曜为辅助 | 四化权重调整 |
| **倪海厦派** | 安星法、部分星曜排布差异 | 安星模块增加倪师分支 |

> 切换开关放在排盘入参中 `school: 'sanhe' | 'feixing' | 'sihua' | 'nishi'`，默认 `'sanhe'`。

### 2.3 网页端系统（PC 端主力使用端）

#### 技术栈
| 项 | 选型 | 理由 |
|----|------|------|
| 框架 | Vue 3 + Vite | 轻量、高性能、TS 友好 |
| 状态管理 | Pinia | Vue3 官方推荐 |
| 样式 | TailwindCSS + 自定义国风主题 | 快速开发 + 精细定制 |
| 盘面绘图 | SVG | 矢量缩放、无失真、动态交互友好 |
| 路由 | Vue Router 4 | SPA 标准 |
| 构建 | Vite 打包 | 本地运行 + Vercel 部署 |

#### 页面规划

1. **首页/录入页**
   - 生辰输入：公历/农历切换
   - 出生地点：自动计算经纬度、真太阳时
   - 性别选择
   - 时区选择（默认东八区）
   - 排盘流派选择（三合/飞星/四化/倪师，默认三合）
   - 「开始排盘」按钮

2. **本命全盘主页**
   - **圆盘可视化**：SVG 绘制十二宫圆盘
     - 十二宫扇形分区，宫名 + 宫干宫支
     - 主星放大高亮，辅煞星浅标小字
     - 四化标注（化禄/权/科/忌 用红/紫/蓝/黑四色标记）
     - 十二地支对应传统神兽暗纹（低透明度）
     - 云纹边框
   - **侧边信息栏**
     - 五行局、命主、身主
     - 本命四化汇总
     - 全盘格局汇总
     - 整体命格简述（自动生成）
   - **交互**
     - 悬浮星曜弹出详解卡片（庙旺状态、吉凶含义）
     - 点击宫位高亮 + 显示宫位详解
     - 盘面缩放（鼠标滚轮）

3. **分运分页**
   - 大限盘（默认显示当前大限）
   - 流年盘
   - 流月盘 / 流日盘
   - 时间轴滑块：年份/月份快速切换
   - 叠加运势星曜标注

4. **资料知识库**
   - 星曜详解（全部 108 星）
   - 格局释义（60+ 格局）
   - 紫微基础名词科普
   - 内嵌静态文档，可全文搜索

5. **导出功能**
   - 命盘图片保存（PNG）
   - PDF 存档
   - 盘面 JSON 数据导出（方便开发者对接）

### 2.4 微信小程序端（移动端随身查看）

#### 技术栈

| 项 | 选型 |
|----|------|
| 框架 | Uniapp (Vue3) |
| UI | uView UI 国风组件 |
| 算法 | 直接复用 `src/core/` 打包的 JS 算法文件（Rollup 打包为单一 UMD） |
| 存储 | uni-storage 本地缓存生辰记录 |

#### 功能规划（轻量化）

1. **首页**：快速排盘入口 + 最近查看的生辰列表
2. **排盘页**：输入生辰 → 显示简化本命盘
3. **盘面查看**：
   - 双指缩放、拖动
   - 长按星曜弹出释义
   - 宫位切换（本命/大限/流年）
4. **记录管理**：常用生辰本地缓存，无需重复填写
5. **分享**：生成盘面图片分享给好友
